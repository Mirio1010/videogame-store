An E-Commerce Website

This project should be approached through vertical slices.

That means your team should not think only in terms of frontend only, backend only, or database only. Instead, your team should think in terms of features that go across the whole stack.

For example, one vertical slice could be:

product listing page

backend route to get products

database table/collection for products

frontend display

filtering or searching

error handling

Another slice could be:

user signup/login

frontend form

backend authentication route

database user storage

validation

protected views

Another slice could be:

shopping cart

add to cart

update quantity

remove item

checkout flow

order storage

Each slice should move through the frontend, backend, and database.
