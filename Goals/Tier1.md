TIER 1: MVP Shopping Experience

As a customer/visitor, I want to be able to:

access a deployed version of the website so I can browse and purchase products

view all available products so I can pick from a variety

view a single product so I can see more details, including the product name, price, description, and image

add a product to my cart so I can collect my desired products in one place

edit my cart if I change my mind:

change the quantity of a product in my cart

remove a product in my cart

see a running total of my cart so I know how much I am about to spend before checking out

have a cart that only I can edit

“checkout” the items in my cart so I can purchase my desired goods; you may begin by simulating checkout with a simple confirmation page

create an account so I can have a logged-in experience

log in and log out of my account so I can secure my session and personal information

see clear error messages when I enter incorrect login credentials so I know what went wrong and how to fix it

search for a product by name so I can quickly find what I am looking for

see a product not found message when I search for something that does not exist

view a navigation bar on every page so I can easily move between sections of the site

see the number of items currently in my cart reflected in the navigation bar

navigate back to the home or products page easily if I get lost

As a logged-in customer, I want to be able to:

have a persistent cart so I can revisit and pick up where I left off, including across devices

see my name or username reflected somewhere on the page so I know I am logged in

have a cart that only I can edit

As an administrator, I want to be able to:

have validated data to ensure reliability

make sure each customer account is unique by email

have full rights to make backend requests to add, edit, and remove products

view user information, with access restricted to admins

As an engineer, I want to:

have a well-seeded database to simulate many scenarios

have a clear and consistent RESTful API

have meaningful error handling on both client and server

have reusable components to keep the codebase clean and organized

keep user data secure, including hashing passwords instead of storing them in plain text
