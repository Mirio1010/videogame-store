# Source (`src`) Folder

This folder contains all the source code for the React application.

- `App.jsx`: The main React component that serves as the root of the app.
- `index.css`: Global CSS styles for the application.
- `main.jsx`: The entry point that renders the React app into the DOM.
- `components/`: Reusable UI components (buttons, headers, etc.).
- `pages/`: Components that represent full pages or views in the app.

All development work should happen inside this folder.
