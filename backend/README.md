# Backend

This folder contains the backend (server-side) code for the Video Game Store project.

## Purpose

- Handles all data processing, business logic, and API endpoints.
- Manages communication between the frontend and the database.
- Runs on Node.js using the Express framework.

## Typical Contents

- `src/` — Source code for the server (API routes, controllers, etc.)
- `package.json` — Lists backend dependencies and scripts.

## For Beginners

If you want to change how the website works (like adding new features, changing how data is handled, or connecting to a database), you will do it here.

To start the backend server:

```bash
npm install
npm run dev
```

Make sure you are in the `backend` folder when running these commands.
