# Pages

This folder contains the main pages of the website.

## Purpose

- Each file represents a different screen or route (like Home, Store, Cart).
- Pages are shown based on the URL the user visits.

## For Beginners

If you want to change what users see on a specific page (like the homepage or the cart), edit the corresponding file here.

Example: `Home.jsx` is the homepage, `Cart.jsx` is the shopping cart page.
